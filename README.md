# SystemHealer

> Diagnose. Repair. Restore.

An all-in-one Windows PC care tool built with React + Spring Boot.

## Features
- System repair (SFC, DISM, network reset)
- Deep uninstaller with leftover cleanup
- Cache & junk cleaner
- Software updater
- Duplicate file finder
- Recovery & restore points

## Tech Stack
- Frontend: React (TypeScript)
- Backend: Spring Boot (Java)
- Platform: Windows
